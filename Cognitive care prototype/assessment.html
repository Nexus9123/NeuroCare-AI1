🧠 Cognitive Assessment

Let's understand your cognitive performance.

Before You Start

This assessment contains five short cognitive activities. Each activity focuses on a different mental skill.

🧠 Memory Remember and match identical pictures.
🔢 Working Memory Remember numbers and select them in the correct order.
🔷 Pattern Recognition Find the correct pattern in shapes or pictures.
🎯 Attention Focus on the correct information.
⚡ Processing Speed Look at the screen and choose your answer.
Important Notice

This system supports cognitive assessment and practice. It is not a medical diagnostic tool and cannot diagnose dementia, Alzheimer's disease, or other neurological disorders.
